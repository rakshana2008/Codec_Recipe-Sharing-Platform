# Codec_Recipe-Sharing-Platform

## About the Project
Recipe Sharing Platform is a web application where users can share, discover, and search for recipes easily.

## Technologies Used
- Frontend: React.js
- Backend: Node.js and Express.js
- Database: MongoDB

## Features
- Add and share recipes
- Search recipes by title
- Filter recipes by category
- View recipe details
- Delete recipes
- Store recipe information in a database

## Project Objective
The main objective is to create a simple and user-friendly platform
that allows users to share recipes and find their favorite dishes.

## Future Enhancements
- User registration and login
- Upload recipe images
- Rate and review recipes
- Save favorite recipes
